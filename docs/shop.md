# Магазин

В этом документе рассказано о принципе работы магазина и всего с ним связанного в Circle Shot.

## Валюта и предметы

Основная валюта - монеты (в народе колобкоины или колобкомонеты). Где их можно получить:
- За игру в события с другими игроками
- За игру в испытания
- Подарки
- Покупка за реальные деньги

Добавление других валют не планируется.

Предметы могут быть следующими:
- Ящики со скинами и экипировкой и их элитные версии (`skin_box`, `skin_elite_box`, `equip_box`, `equip_elite_box`)
- Оружие (`weapon`)
- Навык (`skill`)
- Скин (`skin`)
- Монеты (`coins`)

Главный метод для наград - `Main.receive_loot`. Он принимает массив элементов типа `String`, где каждый элемент имеет формат `<предмет>:<количество или ID>`. Количество принимают ящики и монеты, а ID - оружия, навыки и скины. Ещё существует метод `Main.verify_loot`. Он из такого же массива уберёт уже имеющиеся и/или неизвестные предметы. `Main.receive_loot` вызывает его, прежде чем показать награды.

Чтобы узнать количество монет, вызовите `Globals.get_int("coins")`. Выдавать монеты стоит с помощью `Main.receive_loot`, вручную же монеты стоит менять, когда экран получения наград неуместен (например, конец события).

Проверить наличие предмета экипировки можно с помощью `Globals.items_db.has_equip_item("<ID предмета>", ItemsDB.Item.<ТИП ПРЕДМЕТА>)`. Тут же стоит сказать, что в контексте магазина экипировка - оружия и навыки, однако в контексте игры это и оружия, и навыки, и скины.

## Система предложений

В полночь по местному времени игрока обновляются ежедневные акции (см. `_generate_daily_offers` в `shop.gd`), также включающие в себя подарок. Цены предметам устанавливаются в корневом узле `shop.tscn`.

Игра из скачанного файла с данными достаёт онлайн предложения. Для подробностей о их создании обратитесь в [server.md](./server.md#предложения-в-магазине).

Также существует система специальных предложений, которые могут появляться по ходу сюжета или в качестве награды за испытание. Такие специальные предложения хранятся в переменной `special_offers` типа `Array[Dictionary]`. Каждый словарь в этом массиве должен иметь следующие значения:
- `name`: имя предложения типа `String`
- `id`: ID предложения, начиная с 500, типа `int`
- `sale`: размер скидки в процентах типа `int`, который показывается рядом с ценой, установите в 0 чтобы скрыть
- `cost`: цена в монетах типа `int`, 0 если бесплатно
- `rewards`: массив наград типа `Array[String]`, такой же, который принимает `Main.receive_loot`

## Система промокодов

В игре есть система промокодов двух видов - встроенных и онлайн. Как создавать онлайн промокоды см. [server.md](./server.md#промокоды). Встроенные же промокоды задаются в `promocodes.tscn`, в свойстве `Promocodes` типа `Dictionary[String, String]` коренного узла. Ключ - сам промокод обязательно в нижнем регистре, а значение - массив наград с элементами через запятую, затем точка с запятой и комментарий, который отобразится игроку после активации промокода. Каждый промокод можно использовать только один раз.

## Ящики

Большая часть механики ящиков описана в самой игре, здесь же будут описаны некоторые дополнения.

Шанс предмета секретной редкости считается независимо от остальных редкостей и не повышается при получении предмета "Повышение шансов". Наличие неразблокированных предметов секретной редкости не влияет на то, будут ли в ящике одни монеты.

Шансы всех редкостей задаются в корневом узле `loot.tscn`. Держите их одинаковыми со значениями в `shop.tscn`.
