# Сервер игры

В этом документе описана структура сервера, с которого загружаются данные для игры, и файлов на нём.

## Определение сервера

Адрес для сервера по умолчанию - `https://diamondstudiogames.github.io/circleshot` - записан в `Main.SERVER_URL`. Если Вы хотите поменять этот адрес, то просто отредактируйте константу.

## Файлы на сервере

- `check.txt`: файл, который должен содержать в себе лишь 1 слово: *circleshot*. Используется для проверки подключения к серверу и опознавания, что это именно сервер с данными для Circle Shot.
- `data.cfg`: файл, который игра скачивает при каждом запуске. Содержит самую разную информацию (см. ниже). При успешной загрузке этого файла с сервера доступ к нему можно получить через `Globals.remote_data_file`. Иначе же это свойство будет равно `null` (помните это, прежде чем обращаться к нему!).
- `patches`: папка, в которой находятся последние версии патчей с именем `<версия для патчинга>.pck`.

## Структура `data.cfg`

Макет файла:
```ini
[versions]

stable="<стабильная версия>"
beta="<бета-версия>"

[patches]
<версия для патчинга>=<код последнего патча>
...

[promocode_<промокод>]
comment="<Комментарий, появляющийся после использования>"
only_for_ids=Array[String]([<список ID сохранений, которым доступен этот промокод>])
rewards=Array[String](["<награда>:<количество или ID>", ...])

[offer_<ID предложения, начиная с 1000>]
name="<название предложения>"
cost=<стоимость в монетах>
sale=<визуальный процент скидки>
only_for_ids=Array[String]([<список ID сохранений, которым доступно это предложение>])
rewards=Array[String](["<награда>:<количество или ID>", ...])
```

Разберём каждую секцию по отдельности.

### `versions`

Содержит всего два значения - `stable` со стабильной версией игры и `beta` с нестабильной. Используется при проверке наличие обновлений.  
**Внимание**: если стабильная версия выше нестабильной (например, релиз `2.1.0` когда как последняя бета - `2.1.0.22`), то установите значение `beta` *равным* значению `stable`. Это необходимо для правильной проверки обновлений.

### `patches`

Содержит список значений, где ключи - названия версий (например, `2.2.0.01`), а значение - номер патча (начинается с 1). Каждый раз, когда выпускается новый патч для одной версии, его номер должен повышаться на 1.

### Промокоды

Каждый промокод - секция с названием `promocode_<промокод>`, где `<промокод>` - сам промокод в нижнем регистре. В этой секции обязательно должно быть значение `rewards` типа `Array[String]` и `comment` типа `String` - комментарий, появляющийся после использования. Подробнее о формате массива наград смотрите [здесь](#формат-массива-наград). Также в секции может находится значение `only_for_ids` типа `Array[String]`. Оно определяет список ID сохранений, которым доступен этот промокод.

### Предложения в магазине

Каждое предложение - секция с названием `offer_<ID предложения>`, где `<ID предложения>` - число больше 1000. В этой секции обязательно должны быть значения `name` - имя предложения (таким, каким его видят игроки), `cost` - цена предложения (0, если должно быть бесплатным), `sale` - процент скидки (чисто визуально, 0 чтобы скрыть) и `rewards` типа `Array[String]` - награды этого предложения. Подробнее о формате массива наград смотрите [здесь](#формат-массива-наград). Также в секции может находится значение `only_for_ids` типа `Array[String]`. Оно определяет список ID сохранений, которым доступно это предложение.

### Формат массива наград

Каждый элемент массива - строка формата `<награда>:<количество или ID>`, где `<награда>` - одно из следующих значений:
- `weapon` - оружие. После двоеточия надо указать его ID.
- `skill` - навык. После двоеточия надо указать его ID.
- `skin` - скин. После двоеточия надо указать его ID.
- `coins` - монеты. После двоеточия надо указать их количество.
- `equip_box` - ящик с экипировкой. После двоеточия надо указать их количество.
- `equip_case` - кейс с экипировкой. После двоеточия надо указать их количество.
- `skin_box` - ящик со скинами. После двоеточия надо указать их количество.
- `skin_case` - кейс со скинами. После двоеточия надо указать их количество.
